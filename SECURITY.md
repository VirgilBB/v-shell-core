# Security

## Report a problem
Email **support@cerebro.host** with "Security" in the subject. We reply within 2 business
days. Please include the steps to reproduce and the v-Shell build number (Settings > About).

There is no paid bug bounty. We credit reporters who want credit.

## Safe harbor
If you test in good faith, against your own devices and computers, without touching other
people's data or disrupting anyone, and give us reasonable time to fix before you publish,
we will not pursue legal action against you.

## Extra permission for security research
In addition to the PolyForm Strict License, Cerebro AI gives anyone, including companies and
paid security researchers, permission to modify and run this code privately in order to find,
reproduce or demonstrate security problems, and to publish short excerpts needed to describe
a problem after it has been fixed or after 90 days, whichever comes first. This permission
does not allow distributing the code or shipping it in a product.

## Supported versions
The latest App Store and TestFlight builds.
